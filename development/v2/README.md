## v2の主な仕様

- 4チャンネルの音声メモリ（M1～M4）、通常再生とループ再生を基本に検討。
- マイクPTTが再生・ループを優先解除。録音は押下中のみ、離すと確定。録音中は無線機へPTTを通さない。
- W25Q32RVCSJM 32Mbit（4MiB）SPI Flash、CH32V003F4P6、NJM2732D、TLP592A(F)、AZ8462-3を使用するレビュー版。
- 電池：単3×3本、AP7333による3.3V供給。J1/J2はRJ45 8P8C。
- コンデンサの最小SMDサイズを0805（2012 Metric）、入手性に応じ1206（3216 Metric）を使用。11個の変更は回路図・PCB上の候補フットプリントに反映済み。
- `v2`は**管理上の版名**であり、回路完成・実機合格を意味しない。
