- **製造承認：あり。** プロジェクト責任者（ユーザー）が2026-11-11に上記v2 ZIPの製造承認を明示した。

## v2設計仕様（今回の製造基準）

- CH32V003F4P6、32Mbit SPI Flash（W25Q32RVCSJM）、NJM2732D、TLP592A(F)、AZ8462-3。
- 単3乾電池×3本、3.3V LDO。マイクと無線機の各RJ45 8P8C。
- M1～M4の4チャンネル録音・再生、ループ再生、マイクPTT優先と録音中の誤送信防止を目標仕様とする。ファームウェアの動作合格は別途管理。
- 最新の回路図・PCB・フットプリントは**11月11日ZIPの内容を優先**。
- 2026-11-10のコンデンサ干渉報告（C7/C10/C16/C19等）は、**旧PCBに対する履歴記録**。11月11日製造承認版の現存不良とはみなさない。
