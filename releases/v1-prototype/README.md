## v1試作の主要仕様

| 分野 | v1試作構成 |
|---|---|
| MCU | CH32V003F4P6 / 3.3V |
| SPI Flash | W25Q32RVCSJM / 32Mbit (4MiB)、208mil SOP-8 |
| 音声回路 | NJM2732Dデュアルアンプ、ADC録音／PWM再生 |
| 自動PTT | TLP592A(F) PhotoMOS |
| マイク音声・PTT切替 | AZ8462-3、3V DPDTリレー |
| 音声メモリ | M1～M4、4チャンネル |
| 想定PCM | 8kHz / 8bit / モノラル（FWで確定・検証が必要） |
| 録音上限 | 連続120秒で安全停止。120秒の保証ではない |
| 電源 | 単3×3本、3.3V LDO |
| 外部接続 | マイク側・無線機側RJ45 8P8C、WCH-Link |
| 操作 | REC＋M1～M4、2色状態LED |
| 主なコンデンサ | C11/C19は1µF・0603、0.1µF群は従来0805。後続v2の1206への置換前 |

ここに記載した機能・構成は当時の設計仕様およびECO資料に基づく。**実機で合格したことは示さない**。旧文書の端子表・部品表は古い回路世代を含むため、実装時はこのZIPの回路図／PCBを正とする。

## 製造検証で確認すること（試作評価）

- [ ] 原本ZIPのSHA-256が記録値と一致することを再照合する
- [ ] KiCad 10で原本プロジェクトを開き、ライブラリ解決・実部品実装位置を確認する
- [ ] 正式ERC：エラー0、警告0
- [ ] GNDゾーン再フィル、正式DRC：エラー0、警告0
- [ ] J1/J2 RJ45の実物端子方向・NPTH・ピン番号、各マイク信号の導通を確認する
- [ ] W25Q32RVのJEDEC ID／書込み／読出し／消去と電源断時の扱いを確認する
- [ ] TLP592A(F)のpin4/5/6、LED駆動、無線機PTT負荷定格を確認する
- [ ] リレーNCの通常パススルーと録音中の送信遮断、マイクPTT優先を実機確認する
- [ ] ADC録音／PWM再生／音量調整／連続録音／ループ間PTT解除を検証する
- [ ] 検証結果を日付・基板個体・ファームウェアcommit・計測値とともに記録する

当時の正式チェックリストは [こちら](../../hardware/reports/ECO_RELEASE_CHECKLIST_2026-10-30_JA.md)。この再整理で未実施項目を完了扱いに変更しない。
