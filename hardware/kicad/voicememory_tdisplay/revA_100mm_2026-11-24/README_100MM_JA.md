# VoiceMemory T-Display Rev.A — 100mm基板外形変更（2026-11-24）

## 基準・目的
- 元データ：`VoiceMemory_TDisplay-2026-11-24_164508.zip`（Prototype発注版）。
- JLCPCBで100×100mm以内の寸法条件に収めるため、長辺104.3mmを**正確に100.0mm**へ短縮。短辺64.4mmは変更なし。
- 本版は**発注済みの104.3mm版とは別版**。以前の発注用`PCB.zip`はこの新形状に使用できません。

## 変更内容
1. 外形（Edge.Cuts）下辺を y=139.08 → 134.78mm へ4.3mm上げる。上辺、左右X座標、ケーブル通し穴は変更しない。
2. CH3・CH4タクトスイッチ（SW4・SW5）を y=132.949 → 128.649mmに移動。CH1・CH2・REC・SLEEP_WAKEは移動しない。
3. 下側2個のM4取付穴を y=133.35 → 129.05mm に移動。上側2個は移動しない。下端からの距離5.73mmを維持。
4. CH3/CH4のF.SilkS表示を4.3mm上へ移動。
5. 移動したスイッチの各端子に接続するトラックの端点（対象11セグメント）を一致させる。
6. 新たな基板外形からはみ出すGNDビア2個を4.3mm上へ移動。
7. 古い配置のままの銅箔ゾーン計算キャッシュ13個を削除。**KiCadでBキーを押し、必ず再塗りつぶしすること**。

## 変更しない内容
- 回路図、電源・PTT・音声回路、制御GPIO、すべてのコンポーネント定数・ネット名
- 上側の部品・スイッチ4個の配置、ケーブル穴、部品のフットプリント、層構成
- 元のPrototype発注版・そのGit履歴

## 製造データ再生成前のチェック（必須）
1. `VoiceMemory_TDisplay.kicad_pro` をKiCad 10.x安定版で開く。
2. PCBエディタの **B** キーでGNDゾーンを再塗りつぶす。
3. `検査 → デザインルールチェッカー`で全項目をチェック。問題があれば製造発注前に修正。
4. 基板外形が **64.4×100.0mm** であること、M4穴4箇所、ケーブル通し穴、6個のタクトスイッチが維持されていることを確認。
5. 新版からF.Cu/B.Cu/F.Mask/B.Mask/シルク/Edge.CutsのGerberとPTH/NPTHドリルを**再出力**する。旧`PCB.zip`を流用しない。
6. JLCPCBへアップロードし、プレビュー表示の外形・ドリル位置・基板寸法を再確認。キャンペーン価格は条件・アカウントにより異なるため100mmでの適用を保証しない。

## 検証の位置付け
S式構文、要素数、配線端点とスイッチパッド中心一致、周辺異ネット銅箔との簡易クリアランス（0.20mm未満なし）を静的検査済み。**KiCad 10実行によるERC/DRCとGerber再出力は未実施**。回路図は変更していないため、16:11版のERC 0件報告を別途参照可能だが、PCBのDRC合格は本版に継承しない。
